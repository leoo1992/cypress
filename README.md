# Cypress — testes end-to-end

Repositório de estudo e experimentação com Cypress 12 para automatizar testes de interface e fluxos de navegação no navegador.

## Stack
- Cypress 12
- JavaScript

## Como executar
Instale as dependências e abra o runner interativo:

```bash
npm install
npx cypress open
```

Para executar os testes em modo headless, use `npx cypress run`.
